# GameSheet Assistant Web v3.7

- Major penalties now retain their full five-minute release time even when a power-play goal is scored.
- Misconduct penalties now retain their full ten-minute release time.
- Penalty release calculations now roll into the next period when the remaining time in the current period is insufficient.
- Web Fill data includes `time_on_period` and a review warning for every cross-period penalty.
- The Chrome helper remains review-only and never clicks **Save Changes**.
