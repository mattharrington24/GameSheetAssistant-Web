# GameSheet Assistant Web v3.9

- Keeps goals whose SportsEngine scorer is an unresolved roster-player template.
- Assigns a deterministic placeholder scorer from the same team, excluding listed assists when possible.
- Adds a visible review warning identifying every inferred scorer.
- The same broken event receives the same placeholder on repeated imports.

The Chrome helper remains version 0.9.2; no extension reload is required for this update.
