# Roster Comparison

Added a quick year-to-year roster comparison tool to the existing GameSheet Assistant.

## Use it

1. Open **Compare Rosters** in the top navigation.
2. Paste the previous-season SportsEngine roster URL.
3. Paste the current-season SportsEngine roster URL.
4. Select **Compare Rosters**.

The results show returning, new, and departed players. Names can be copied from
each section. Matching ignores capitalization, punctuation, extra spaces, and
`Last, First` versus `First Last` formatting.
