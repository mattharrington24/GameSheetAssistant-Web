# Version 3.1 — Multiple-goalie web fill

- Infers full-period multi-goalie stints only when minutes played, shots faced, and goals allowed reconcile.
- Adds inferred goalie shifts and period shot splits to the Chrome-helper payload.
- Assigns each goal to the inferred defending goalie.
- Keeps ambiguous or mid-period changes manual and displays a review warning.
- Chrome helper 0.7.0 fills inferred goalie shifts, goalies on goals, and goalie shot rows without saving the form.
