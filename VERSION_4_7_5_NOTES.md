# Version 4.7.5

- Recognizes spaces, standard hyphens, nonbreaking hyphens, and en dashes in
  `Cross Checking` while preserving it as `Cross-Checking`.
- Keeps plain `Checking` mapped to `Body Checking`.
- Designed to pair with Chrome helper v0.9.17, which requires an exact checking
  offense match instead of allowing fuzzy substitution.
